# GDI / GDI+ reference fixtures

`src/__fixtures__/gdi` holds metafiles paired with PNGs that Windows itself
painted. The pixel-parity tests (`src/__fixtures__/gdi-parity-harness.ts`)
replay each metafile through the converter and compare against the PNG.

| File | What it does |
| --- | --- |
| `GdiFixtures.cs` | The case groups. Each case records the drawing into `<name>.emf` / `.wmf` and writes `<name>.png`: either the same calls painted onto a 32bpp bitmap, or GDI+'s own playback of the recorded metafile. |
| `PenTransformProbe.cs` | Pen-transform (`Pen.Transform`) cases: `pen-<case>.emf`, `pen-<case>.png` (GDI+ playback) and `pen-<case>-direct.png` (drawn straight onto a bitmap). |
| `generate.ps1` | Compiles both files with `Add-Type` and runs the requested groups. |
| `report.ts` | Parity table for every fixture: `bun scripts/gdi-fixtures/report.ts` (not part of `bun run test`). |
| `generate-mapping-extents.ps1` | Standalone signed rational extent scaling, rejection and 32-bit arithmetic controls, including complete native polygon masks for EMF/WMF replay tests. |
| `capture-bilinear.ps1` | Standalone GDI+ Bilinear arithmetic, cropped/mirrored image and alpha controls captured into premultiplied surfaces. |
| `generate-texture-sampling.ps1` | Standalone TextureBrush controls across transforms, wrap modes and pixel offsets, capturing both straight and premultiplied RGBA. |
| `generate-texture-coordinate.ps1` | Standalone source-coordinate sweeps for texture brushes and plain Bilinear `DrawImage` (`TextureCoordinateProbe.cs`, `ImageCoordinateProbe.cs`) and 4,000 native `Matrix.Invert` results (`MatrixInvertProbe.cs`). The texture sweep takes about ten minutes; `-SkipSweep` keeps the committed one. |
| `generate-translucent-clamp.ps1` | Standalone translucent ImageAttributes Clamp colours (`TranslucentClampProbe.cs`) under four interpolation modes, on straight and premultiplied surfaces over six backdrops with SourceCopy and SourceOver (`translucent-clamp-surfaces.json.gz`). |

Run standalone PowerShell generators with Windows PowerShell, for example `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/gdi-fixtures/capture-bilinear.ps1`. Each accepts `-OutDir` for a separate capture directory and writes an environment manifest with native-library and reference hashes. They do not regenerate the older fixture groups.

The report supplies `windowsFonts()` when the complete fixture font set is available (override its directory with `GDI_FIXTURE_FONTS`). Set `GDI_FONTS=host` to inspect canvas text rendering instead. It identifies the font mode, reports exact RGB pixel counts as well as differences beyond eight levels, and includes the overlap's right/bottom edges. `size` lists rendered/reference dimensions; `outside` counts reference ink missing from the render and rendered ink with no captured reference. White margins are ignored in those counts. Exact common-area RGB does not certify matching bounds or independent alpha. `GDI_FILTER` selects fixture names, `GDI_REPORT` selects the output file, and `GDI_DUMP` saves the same renders used for comparison.

## Supplementary Unicode text controls

`python scripts/gdi-fixtures/build-supplementary-font.py` builds the CC0 diagnostic font (requires fontTools). Then `powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-text-supplementary.ps1` captures 75 native GDI+ DrawString controls across five text hints and three sizes, with an environment manifest. BMP and supplementary Unicode aliases map to identical glyphs so the controls isolate surrogate-pair decoding and advances from font-shape differences. `emf-plus-supplementary-text.fixture.test.ts` compares complete RGBA output exactly and checks supplementary text and glyph positions in vector SVG. The checked-in font and captures make tests portable; Windows is needed only to regenerate references.

## Courier New grayscale controls

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-courier-gray.ps1 -Renamed` captures 6,400 native size/style/hint/quarter-origin controls and 1,600 private-family controls. The optional rename comparison requires Python fontTools; its copy of the installed Windows font stays under `.scratch/` and is not bundled. Environment manifests record the inputs. `gdiplus-courier-gray.fixture.test.ts` retains individual before/after bounds, including five small increases in already-inexact cases, and checks that no previously exact control is lost. The family-specific widening applies only to regular/italic GDI+ AntiAlias; bold, grid fitting, matrices and synthetic styles are excluded.

## GDI grayscale text blend and glyph bitmaps

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-gray-blend.ps1` (probe `GrayBlendProbe.cs`) draws a 40 px Arial glyph sheet with `TextOut` / `ExtTextOut` at ANTIALIASED_QUALITY onto a 32-bit DIB section and records, per glyph coverage level (the pixel's grey in the black-on-white sheet), the output for grey text over grey backgrounds (every third grey; `GRAY_GRID=full` for the 256 x 256 sweep that fixed the model) in TRANSPARENT and OPAQUE mode, for random colour pairs in six drawing modes (TRANSPARENT, OPAQUE, `ETO_OPAQUE` whole and half rectangles, `ETO_CLIPPED` alone and with OPAQUE mode), and a sweep of each `ETO_OPAQUE` rectangle edge across the text cell for eight font/string combinations (`gray-blend.json.gz`, `environment-gray-blend.json`; test `src/gdi-gray-blend.fixture.test.ts`, model `src/gdi-gray-blend.ts`).

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-gray-glyphs.ps1` (probe `GrayGlyphProbe.cs`) captures `GetGlyphOutline` `GGO_GRAY4_BITMAP` and `GGO_NATIVE` (the hinted outline) for every printable ASCII glyph of Arial, Times New Roman, Tahoma, Segoe UI and Courier New at 18, 24, 32, 48 and 72 px (`gdi-gray-glyphs.json.gz`, `environment-gray-glyphs.json`; test `src/gdi-gray-glyphs.fixture.test.ts`). `GetGlyphOutline` ignores the font's `gasp` table, so sizes at which `ExtTextOut` draws a font monochrome are not comparable with this capture.

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-hint-sweep.ps1` (probe `HintSweepProbe.cs`, fonts `build-hint-sweep-fonts.py`) builds private fonts whose glyphs run ONE TrueType instruction (MIRP, MDRP, MDAP, ALIGNRP, IUP) 48 times on random points after a projection vector set by SPVTL/SDPVTL at a swept angle, and reads the result through `GetGlyphOutline(GGO_NATIVE)` at 16 and 24 ppem (`hint-sweep-*.ttf`, `text-hint-sweep.json.gz`, `environment-hint-sweep.json`; test `src/ttf-hint-sweep.fixture.test.ts`). `HINT_SWEEP_ONLY=all` builds every kind (61), `HINT_SWEEP_VECTORS` sets the vectors per font. `GetGlyphOutline` ignores `lfQuality`, so ClearType hinting cannot be read this way.

## Rotated GDI text (round 8)

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-rotation-matrix.ps1` (probe `RotationMatrixProbe.cs`, fonts `build-rotation-matrix-font.py`) reads `GetGlyphOutline(GGO_NATIVE)` of private fonts under a world rotation and under an escapement, 0 to 355 degrees in 5-degree steps, to expose the matrix GDI applies to a rotated glyph. `axisint` (2048 units per em, `head.flags` bit 3, points 1700 to 1938 units along the x axis) at 19 sizes and `plain` (64 units per em, no flag, points 468 em out) at 2: `rotation-matrix.json.gz`, `rotation-matrix-axisint.ttf`, `rotation-matrix-plain.ttf`, `environment-rotation-matrix.json`; test `src/gdi-rotation-matrix.fixture.test.ts`. `ROT_SIZES`, `ROT_STEP`, `ROT_VARIANTS`, `ROT_ALL_POINTS=1` narrow or widen the sweep; `ROT_ALL_FONTS=1` also builds the other variants (programs only, integer-ppem flag, 240 random points per glyph), which were run during the investigation and are not committed.

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-rotated-metrics.ps1` (probe `RotatedMetricsProbe.cs`) reads `GetTextMetrics` ascent and descent of five faces at lfHeight -8 to -60 and lfEscapement 0, 90, 180, 270, 25, 45, 160 and 300 degrees (`rotated-text-metrics.json.gz`, `environment-rotated-metrics.json`; test `src/gdi-rotated-metrics.fixture.test.ts`).

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-rotated-bitmaps.ps1` runs `TextRotatedPlacementProbe.RunGlyphs` with `GLYPH_CHARS`, `GLYPH_HEIGHTS`, `GLYPH_DEGREES` and `GLYPH_OUTPUT` set to the glyphs of the rotated-text fixtures ("TgEscap0123456789", -13, -16 and -20 px, 25 to 315 degrees including the 45-degree diagonals): `rotated-glyph-bitmaps-small.json.gz` (GGO_BITMAP and GGO_NATIVE; test `src/gdi-rotated-glyph-bitmaps.fixture.test.ts`). A GGO_BITMAP row is padded to a DWORD: for glyphs wider than 32 pixels it takes more than four bytes.

## Monochrome stub and DrawString spacing controls

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-mono-stubs.ps1` captures native monochrome glyph masks using generated diagnostic fonts. `build-mono-stub-fonts.py` rebuilds those fonts with Python fontTools. Original, independent and held-out sets total 29,696 controls; `ttf-mono-stub.fixture.test.ts` checks complete ink coordinates, individual bounds and preservation of previously exact cases. Curves and multiple contours remain diagnostic controls; the new runtime rule is limited to straight single-contour outlines.

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-drawstring-advances.ps1` captures native repeat-glyph and mixed-string spacing evidence. `gdiplus-drawstring-advances.fixture.test.ts` pins the current per-case baselines. These captures rejected two candidate ClearType spacing corrections; they do not establish a complete layout model. See the text follow-up in `docs/native-parity-review.md` for the measured counterexamples.

`powershell.exe -NoProfile -File scripts/gdi-fixtures/generate-text-advances.ps1` (probe `TextAdvanceProbe.cs`) captures the mean DrawString advance of every printable ASCII glyph of Arial, Arial Bold, Times New Roman and Tahoma at 12, 16, 20 and 40 px, default and GenericTypographic format, AntiAliasGridFit and ClearTypeGridFit (`text-advances.json.gz`, `environment-text-advances.json`; test `gdiplus-text-advances.fixture.test.ts`). ClearTypeGridFit advances a glyph by its ClearType phantom-point advance rounded to a pixel (every whole-number glyph of the default format); AntiAliasGridFit by the widths of GDI's own interpreter.

The monochrome generator also captures 1,200 real-font controls using `MonoCondensedProbe.cs`; `ttf-mono-condensed.fixture.test.ts` preserves every prior per-case ceiling and 970 exact controls. The smart-crossing refinement is restricted to upright, uniformly realized glyphs without synthetic shear or fractional translation. Condensed glyphs retain the previous arithmetic where refinement exposes unresolved hinting/raster interactions; existing real-font residual limits remain unchanged.

Additional diagnostic groups:

- `translucent-clamp-surfaces` (standalone): 576 draws of a 4 x 3 mixed-alpha source at 1x and 2.5x with a Clamp colour of alpha 40, 160 or 255 and RGB (217, 43, 129). GDI+ reads the RGB as literal premultiplied bytes (a pixel can hold a channel above its alpha), and a SourceOver draw onto a premultiplied surface is a 32-bit add of the pixel and the backdrop times (255 - alpha) / 255, carries included (all 6,578 touched pixels). `src/emf-plus-translucent-clamp.fixture.test.ts` pins both.
- `texture-coordinate` (standalone): 16 sweeps of a 2 x 2 Tile texture (red and green are the texel parity, values 0 and 1) filled over 160 x 8 pixels (or 120 from x = 40 as a rectangle and as a clip) while the brush translation moves in 65,536 steps of a power of two (`texture-coordinate.json.gz`, `TextureCoordinateProbe.cs`). The draw at which each pixel's red or green flips is its native coordinate, independent of any model: the position drifts below the exact one by up to a float32 unit per pixel, because each pixel adds the matrix's x step in float32 rounded toward minus infinity. `src/emf-plus-texture-coordinate.fixture.test.ts` pins the misses per sweep. `image-coordinate` (7 sweeps of a plain Bilinear `DrawImage` origin by 2^-16 pixel, `ImageCoordinateProbe.cs`) `image-levels` (8 sweeps of the destination origin of a HighQualityBilinear/HighQualityBicubic `DrawImage` of grey noise, one axis at a time, recording for every pixel the draws at which its red changes and the new level, `ImageLevelProbe.cs`) and `matrix-invert` (4,000 native `Matrix.Invert` results as float32 bits, all reproduced by float32 operations that round toward minus infinity) are captured by the same script.
- `path-gradient-span` (standalone, `generate-path-gradient-span.ps1`, `PathGradientSpanProbe.cs`, `path-gradient-span.json.gz`): per-vertex path gradients (a fan triangle with one vertical edge and two 256-row edges, colours in multiples of 64) built so the two end colours of every scanline are exact in any arithmetic, 108 images of 580 rows (60 random colour triples, 48 "flat" fans whose two end colours are equal on every row), red and alpha kept. Every one of the 2,631,233 pixels that is not an exact half-level tie has the nearest level of the exact interpolation, which rules out a stepped delta; a flat span at a half level is all up for 2^k pixels and up-then-down for an odd length (`src/emf-plus-path-gradient-span.fixture.test.ts`, which also holds the test-only single-precision candidate `src/__fixtures__/path-gradient-vertices-candidate.ts`). `-Argb` also writes `path-gradient-vertices-argb.json.gz` (the per-vertex captures on a straight-alpha surface with SourceOver; opaque captures are identical to the committed ones, so the destination format is not a factor).
- `linear-ramp-origin` (standalone, `generate-linear-ramp-origin.ps1`, `LinearRampOriginProbe.cs`, `linear-ramp-origin.json.gz`): the origin of a linear gradient's ramp coordinate read to one 16.16 unit. The **Windows fixtures** workflow (`.github/workflows/windows-fixtures.yml`)


   everything). `push` (default on) controls the branch push.
2. The run uploads every new or changed fixture as the artifact
   `windows-fixtures-<run_id>` and commits them to the branch
   `windows-fixtures/<run_id>`. It never pushes to `main`. The run summary
   lists the files.
3. Bring the files into your checkout, either:

   ```sh
   # from the branch
   git fetch origin windows-fixtures/<run_id>
   git checkout origin/windows-fixtures/<run_id> -- src/__fixtures__/gdi
   ```
