emf-converter

A zero-dependency TypeScript library that converts EMF (Enhanced Metafile) and WMF (Windows Metafile) binaries into PNG data URLs or SVG (markup, a data URL, or React/JSX), replaying their GDI and GDI+ drawing records entirely in the browser.

zero dependencies EMF EMF+ WMF Node.js (optional) Apache-2.0

replays record streams like EMR_HEADER → EMR_SETWORLDTRANSFORM → EMR_SELECTOBJECT → EMR_STRETCHDIBITS → EMR_EOF

Install

npm install emf-converter

No required dependencies. In a browser or Web Worker, OffscreenCanvas or HTMLCanvasElement is picked up automatically.

Node.js

Plain Node.js has neither of those, so install the optional @napi-rs/canvas package and conversion uses it instead: 

npm install @napi-rs/canvas

It's a prebuilt, Skia-based native module, no node-gyp build step. Skip it and a call in plain Node.js resolves to null instead of throwing.

Usage

import { convertMetafileToDataUrl } from 'emf-converter';

// `buffer` is an ArrayBuffer loaded from a file, fetch(), or an Office doc.
const pngDataUrl = await convertMetafileToDataUrl(buffer);
// => "data:image/png;base64,iVBORw0KGgo..."  (or null on failure)

// Works the same for WMF; the format is detected from the bytes.
const wmfPng = await convertMetafileToDataUrl(wmfBuffer);

// Optional: clamp output dimensions (aspect ratio preserved).
const scaled = await convertMetafileToDataUrl(buffer, { maxWidth: 1024, maxHeight: 768 });

Returns Promise<string | null>, the PNG data URL, or null when the buffer is invalid or no Canvas backend is available.

SVG and React

import { createElement } from 'react';
import { convertMetafileToSvg, convertMetafileToSvgTree, svgTreeToReact } from 'emf-converter';

// Standalone markup (no canvas needed, works in plain Node.js too).
const svg = await convertMetafileToSvg(buffer);

// Live React elements, sized and styled like any other element.
const tree = await convertMetafileToSvgTree(buffer);
const element = tree && svgTreeToReact(tree, createElement, { width: '100%' });

How it works

A three-phase pipeline: parse, replay, export. The header parser reads the drawing bounds, a Canvas is created and capped at 8192×8192 pixels (raise it with maxCanvasDimension), then records are scanned in order and dispatched to GDI, EMF+, or WMF handlers that drive the Canvas 2D context. Embedded bitmaps (DIB and GDI+ pixel formats) and recursively embedded metafiles resolve asynchronously once the synchronous replay finishes, then the canvas is exported as a data:image/png;base64,… URL.

WMF Windows Metafile (16-bit), window/viewport mapping.
EMF Enhanced Metafile (32-bit GDI), bounds-based scaling.
EMF+ GDI+ extension embedded in EMF, world transform matrix.

Capabilities

  • PNG or SVG output. The same replay drives a Canvas (PNG data URL) or an SVG recorder that needs no canvas at all: markup, a base64 data URL, React elements, or a generated TSX component.
  • Exact clip combine modes. Intersect, Union, Xor, Exclude, Complement, and Replace are exact for every clip, including multi-shape and path-bracket clips, for GDI region ops and EMF+ region-node trees.
  • Gradients and textures. GDI+ linear gradients with preset colours and every WrapMode, true boundary-shaped path gradients, and texture brushes, verified against real GDI+ output.
  • Raster operations. All 256 ROP3 codes are evaluated bit-for-bit against the destination, and the bitwise SetROP2 modes are exact too.
  • Windows-exact rendering. GDI shapes, pens, dashes and blits use a rasteriser fitted to Windows GDI, and EMF+ follows its recorded SmoothingMode with GDI+'s own rasteriser, checked pixel for pixel against Windows.
  • 300+ EMF record types, the full EMF+ (GDI+) record set, and legacy WMF records: state, objects, shapes, paths, text, bitmaps, and clipping.

Limitations

  • Text needs the right fonts. Pass the font files a metafile uses (fonts, or loadSystemFonts() in Node.js) for GDI-exact text; otherwise the host font engine is used. This demo uses your browser's fonts.
  • ClearType text is within a few percent of Windows' pixels; non-antialiased and grayscale text are near-exact.
  • Safety limits. Output is clamped to 8192×8192 and replay stops after 200,000 records (EMF/WMF) or 500,000 (EMF+), all overridable via maxCanvasDimension / maxRecords.
